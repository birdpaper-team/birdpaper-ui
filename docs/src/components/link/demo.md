## 基础用法

通过 `status` 属性设置链接状态，支持 `primary`（默认）、`success`、`warning`、`danger`、`gray`。

## 尺寸

通过 `size` 属性设置链接尺寸，支持 `mini`、`small`、`default`、`large`。

## 禁用与加载

通过 `disabled` 属性禁用链接，`loading` 属性显示加载状态，`loading-icon` 可切换加载图标（1-5）。
