## 基础用法

通过 `count` 属性设置徽章的数值，当数值超过 `max-count` 时显示为 `max-count+`。

## 状态

支持 5 种状态类型：`gray` - <b>灰度</b>，`primary` - <b>主要（默认）</b>，`success` - <b>成功</b>，`warning` - <b>警示</b>，`danger` - <b>危险</b>。
