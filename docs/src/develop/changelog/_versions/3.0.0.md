## <span class="changelog-version">3.0.0</span><span class="changelog-date">2026-08-24</span>

Birdpaper UI v3（Blue）正式发布。基于 Vue 3 全面重写，补齐设计体系、主题定制与深色模式，并提供完整 TypeScript 类型与可按需引入的组件包。

### 破坏性变更

- 最低依赖提升为 **Vue 3.5+**，不再兼容 Vue 2 / Vue 3.4 及以下
- 主题改为 **CSS 变量**驱动，请改用 `birdpaper-ui/theme/index.css`（或按需 `theme/*.css`）引入样式
- 深色模式根类名统一为 **`.dark`**（不再使用 `.bp-dark`），业务侧切换逻辑需同步调整
- 弹出层默认基准层级调整为 **`zIndex: 3000`**，并与 `--z-index-base` 对齐
- 包结构改为 monorepo 产物（`es` / `lib` / `theme` / `types`），请按 [安装](/develop/install/) 文档更新引入方式

### 设计体系

- 全新色彩体系：功能色（Primary / Success / Warning / Danger）与中性色各 10 阶，浅色 / 深色双套 Token
- 统一尺寸规范：`mini` / `small` / `default` / `large` 四级高度、字号、内边距与圆角
- 补齐阴影、间距、动效与 z-index 层级规范，组件共享同一套设计令牌
- 提供设计原则、样式指南、深色模式与设计资源文档，便于设计与研发对齐

### 新功能

- **ConfigProvider / 全局配置**：支持 `prefix`、`namespace`、`locale`、`size`、`zIndex`、`emptyText`
- **主题定制**：覆盖 `--bp-primary-*`、`--bp-size-*` 等变量即可改品牌色与组件尺寸
- **深色模式**：根节点切换 `.dark`，语义色与中性色自动映射，组件无需额外适配
- **按需引入**：支持 Tree-shaking，可单独引入组件与对应样式
- **日期时间**：DatePicker、DateRangePicker、MonthPicker、YearPicker、TimePicker
- **表单增强**：InputTag、InputNumber、VerifyCode、ColorPicker，以及 Form 校验能力
- **数据展示**：Table（固定列 / 滚动 / 选择等）、Statistic、Rate、Badge、Empty、Image、Avatar、Tag
- **导航与反馈**：Steps、Pagination、Dropdown、Modal、Drawer（支持异步确认）、Message、Popconfirm、Tooltip、Spin、Alert
- **布局与基础**：Grid、Space、Button / ButtonGroup、Link、Switch、Checkbox、Radio、Select、Trigger
- 图标 [birdpaper-icon](https://icon.birdpaper.design)
